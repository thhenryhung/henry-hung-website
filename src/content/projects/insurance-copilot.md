decisions:
  - title: "LLM-assisted priority over manual triage"
    chose: "A ranked queue in which the co-pilot weighs several customer signals, then explains both the recommendation and the evidence behind it."
    over: "Asking each agent to review every open relationship and decide whom to contact first using judgment alone."
    because: "No single rule captured priority. The LLM combined several signals, while explanations made its reasoning inspectable. The tradeoff was inconsistent rankings and initial agent skepticism."
  - title: "Draft-and-approve over fully automated replies"
    chose: "The co-pilot drafts a reply for the agent to review and send; it never sends on its own."
    over: "A genuinely considered version that sent AI-generated outreach without human review."
    because: "Review protected accuracy and compliance, preserved relationship nuance and kept agents in control—critical to adoption."
  - title: "Proactive recommendations without alert fatigue"
    chose: "Surfacing a recommendation only after it cleared a confidence or expected-value threshold, then letting agents dismiss or rate it."
    over: "Showing every possible trigger and asking agents to separate meaningful opportunities from noise."
    because: "A smaller set of credible prompts protected attention, while agent feedback improved later suggestions."
outcome: "In prototype tests with roughly twenty frontline agents, thirty percent of replies were accepted unchanged or lightly edited. Preparation fell from fifteen to thirty minutes per conversation to under five.\n\nThe work helped secure C-suite sponsorship for a multi-year roadmap. Next, I would start with fewer, higher-value triggers before expanding recommendations."
